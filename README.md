# Práctica 2.1. Ejercicios sobre ficheros

Programa de consola en C# para trabajar con ficheros de texto desde un menú:

1. Crear un nuevo fichero con el nombre que se pasa por consola.
2. Añadir registros en el fichero.
3. Eliminar todos los registros del fichero.
4. Eliminar el fichero.
5. Visualizar los registros.
6. Cerrar la aplicación.

## Cómo ejecutarlo

```
dotnet run
```
